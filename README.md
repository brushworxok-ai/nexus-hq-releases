# Nexus HQ signed desktop releases

This public repository is the binary-only update channel for the private Brushworx Nexus HQ admin desktop application.

It contains only:

- the current signed Windows installer
- its detached Tauri updater signature
- `latest.json`, the static updater manifest

It contains no application source code, credentials, customer information, or Brushworx business data. Installing the binary does not grant access to Nexus HQ; an authorized Brushworx account is still required.

Release files are produced by the reviewed private source workflow and verified by the public updater key embedded in Nexus HQ. Do not upload files here manually.
